原画 / 语音拷贝

在整合包之间复制武将原画、阵亡语音和技能语音。

技能文件

复制 Lua 技能文件，支持技能 ID 补全与目标重命名。

语音下载

按 URL 下载语音并落到指定包与技能。

技能测试

调用 FreeKill 的 -testfile 并汇总测试输出。

快速启动

生成 quick_start.json，一键启动 FreeKill -q。

终端优先

Bubble Tea 全屏 TUI，方向键 + Enter 完成全部操作。

快速开始

# 下载对应平台的可执行文件后
chmod +x tui-copier-linux-amd64

# 必须在 FreeKill 项目根目录运行（需要读取 packages/）
cd /path/to/FreeKill
/path/to/tui-copier-linux-amd64

从源码构建

git clone https://github.com/liking008/tui-copier.git
cd tui-copier
go build -trimpath -ldflags "-s -w" -o tui-copier .

快捷键：↑/↓ 选择 · Enter 确认 · Esc 返回/退出 · Tab 切换焦点 · Ctrl+S 提交 · Ctrl+A 全选。
